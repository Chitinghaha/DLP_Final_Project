CIFAR-100 是常用的小尺寸影像分類資料集，和 CIFAR-10 一樣都是 `32x32` RGB 彩色影像，但分類粒度更細。CIFAR-10 只有 10 個 broad classes；CIFAR-100 則有 100 個 fine classes，並額外整理成 20 個 coarse superclasses。每個 coarse superclass 底下有 5 個 fine classes，因此模型不只要分辨「是不是動物」或「是不是交通工具」，還要在相近的細類別之間做 100-way fine-grained classification。

從「哪些可能相似」的角度看，官方 coarse superclass 是最直接、最客觀的分組；同一組內的 5 個 fine classes 通常共享較多語義或外觀特徵。不過對 post-forget rebound 來說，也要注意跨 superclass 的 shared visual features。可能值得特別觀察的組合包括：

- 動物大群：大型肉食動物、大型雜食/草食動物、中型哺乳類、小型哺乳類、水生哺乳類、爬蟲類。這些類別常共享毛色、身形、臉部、四足姿態或自然背景。
- 水中類別：水生哺乳類、魚類，以及螃蟹 / crab `(26)`、龍蝦 / lobster `(45)` 等非昆蟲無脊椎動物。這些圖像可能共享水域背景、藍綠色調或水生生物輪廓。
- 植物與自然類別：花卉、樹木、水果與蔬菜、大型自然場景。這些類別可能共享植物紋理、葉片、自然背景或相近色彩。
- 人工物與交通類別：車輛 1、車輛 2、大型人工戶外物、家用電器、家具。這些類別可能共享直線邊緣、金屬/塑膠材質、輪廓形狀或人工場景背景。
- 小型物體類別：食物容器、家用電器、家具中的小物件。CIFAR-100 影像解析度只有 `32x32`，小物體在低解析度下更容易因輪廓或背景相似而混淆。

因此，後續若要驗證 old forgotten class 的 post-forget rebound 是否普遍，可以不只看同一 coarse superclass 內的回彈，也可以設計跨 superclass 但視覺相似的 subset。例如「水生哺乳類 + 魚類」、「多組哺乳類」、「植物 + 自然場景」、「車輛 + 人工戶外物」都比隨機抽樣更容易放大 shared representation / decision boundary drift。

原始 CIFAR-100 的資料量如下：

| 項目 | 數量 |
| --- | ---: |
| Total images | `60000` |
| Train images | `50000` |
| Test images | `10000` |
| Fine classes | `100` |
| Coarse superclasses | `20` |
| Images per fine class | `600` |
| Train images per fine class | `500` |
| Test images per fine class | `100` |

本專案訓練 original CIFAR-100 baseline 時，會再從官方 training set 中切出 validation set：每個 fine class 取 10% training samples 作為 validation。因此實際訓練流程使用的是：

| Split | 數量 | 說明 |
| --- | ---: | --- |
| Train | `45000` | 每類約 `450` 張 |
| Validation | `5000` | 每類約 `50` 張，從官方 training set 切出 |
| Test | `10000` | 每類 `100` 張，使用官方 test set |

本專案的 CIFAR-100 前處理也和 CIFAR-10 類似：training 使用 `RandomCrop(32, padding=4)`、`RandomHorizontalFlip` 與 `ToTensor`；validation / test 使用 `ToTensor`。Normalization 沒有直接放在 data transform 裡，而是放在 model 的 normalize layer 中，使用 CIFAR-100 mean `[0.5071, 0.4866, 0.4409]` 與 std `[0.2673, 0.2564, 0.2762]`。

CIFAR-100 比 CIFAR-10 更適合這次 sequential unlearning 觀察，原因有三個：

- Fine classes 更多，而且每一類只有 `100` 張 test images；因此 per-class accuracy 的變化可以直接反映某個細類別是否被遺忘或回彈。
- 類別邊界更細，許多類別共享局部視覺特徵，例如動物的毛色、身形、姿態、自然背景等。
- 100-way classification 比 10-way classification 更容易暴露 decision boundary drift，也就是後續 unlearning 其他 class 時，舊 forgotten class 的分類能力可能被間接帶回。

這次實驗刻意選擇動物類別作為 pilot subset，正是因為動物類別之間共享外觀特徵較多，比較容易觀察 sequential unlearning 中是否會出現遺忘延遲或舊類別回彈。需要注意的是，CIFAR-100 每個 fine class 的 test set 只有 `100` 張圖，所以 `1%` per-class accuracy 約等於 1 張圖；解讀很小的非零 accuracy 時要保守，但若 final accuracy 超過 `10%`，就代表至少約 10 張測試圖仍被正確辨識，較值得標記為 residual / rebound 訊號。

目前採用的 incremental data flow 是：每一步只用當步新指定的 class 做 forget training，舊 forgotten classes 不再回到後續 train loader；累積 forgotten classes 只用於 evaluation。

## 2. 遺忘目標類別

本次 CIFAR-100 pilot 不是遺忘全部 100 類，而是選出 20 個 animal-heavy fine classes，分成四組語義群：

| Group | Classes |
| --- | --- |
| large carnivores | bear `(3)`, leopard `(42)`, lion `(43)`, tiger `(88)`, wolf `(97)` |
| large omnivores / herbivores | camel `(15)`, cattle `(19)`, chimpanzee `(21)`, elephant `(31)`, kangaroo `(38)` |
| medium mammals | fox `(34)`, porcupine `(63)`, possum `(64)`, raccoon `(66)`, skunk `(75)` |
| small mammals | hamster `(36)`, mouse `(50)`, rabbit `(65)`, shrew `(74)`, squirrel `(80)` |

這 20 類在三條實驗線中完全相同，差異只在遺忘順序，避免因為 target subset 不同而影響比較。

## 3. 遺忘順序設計

三條 full run 都是 `seed 1 / k=20`，每一步依序忘掉一個新 class。

`Normal`

```text
3,15,19,21,31,34,36,38,42,43,50,63,64,65,66,74,75,80,88,97
```

Normal 是固定順序 baseline，用來觀察這組 animal subset 在一般排列下是否容易出現遺忘問題。

`Clustered`

```text
3,42,43,88,97,15,19,21,31,38,34,63,64,66,75,36,50,65,74,80
```

Clustered 會連續遺忘同一語義群，例如先連續處理大型肉食動物，再處理大型草食 / 雜食動物。這個設計用來觀察同群 shared features 被連續施壓時，是否能讓 forgetting 更穩定。

`Interleaved`

```text
3,15,34,36,42,19,63,50,43,21,64,65,88,31,66,74,97,38,75,80
```

Interleaved 會在不同 animal groups 間交錯切換，用來測試 heterogeneous order 是否會讓舊 class 更容易回彈，或讓新 forget class 當步比較難壓低。

## 4. 結果重點

三條 CIFAR-100 full `k=20` run 都已完成，final metrics 如下：

| Order | Forget acc | UA | Retain acc | Full test acc |
| --- | ---: | ---: | ---: | ---: |
| Normal | `2.20` | `97.80` | `71.38` | `57.54` |
| Clustered | `1.20` | `98.80` | `71.65` | `57.56` |
| Interleaved | `1.40` | `98.60` | `71.60` | `57.56` |

主要觀察：

- 三條 order 都沒有出現 immediate forgetting lag。若以「newly forgotten class 在當步 accuracy `>10%`」作為 failure 標準，Normal、Clustered、Interleaved 的 lag steps 都是 `0`，最差 newly forgotten accuracy 也只有 `2.0%`。
- Final cumulative forgetting 效果很好。三條 order 的 final forget accuracy 都很低，其中 Clustered 最低，為 `1.20%`。
- Retain side 沒有整體崩壞。Final retain accuracy 約在 `71.38% ~ 71.65%`，和 CIFAR-100 baseline 的整體水準相近，表示 forgetting 不是靠讓整個模型失效達成。
- 比較值得注意的是 old forgotten class 的 post-forget rebound。最明顯的是 `class 21: chimpanzee`，final accuracy 在 Normal 為 `17.0%`，Clustered 和 Interleaved 都是 `11.0%`。這代表該 class 在被忘當下可以壓到接近 `0%`，但後續 sequential updates 可能透過 shared representation / decision boundary drift 讓它局部回升。

簡短結論：目前 CIFAR-100 pilot 顯示方法對當步新指定的 forget class 很有效，沒有看到當步忘不掉的 failure；真正需要後續追蹤的是少數舊 forgotten classes 的 rebound / residual，尤其是 `chimpanzee (21)`。

## 5. Single-Coarse Rebound Probe：重新檢查 old forgotten class rebound

為了進一步確認 old forgotten class 的 post-forget rebound 是否具有普遍性，後續又設計了 9 條 `single coarse superclass` 實驗。每條 run 固定 `seed=1`、`MAX_K=5`，只忘同一個 CIFAR-100 coarse superclass 裡的 5 個 fine classes。

這次選三個 coarse superclass：

| Coarse superclass | Fine classes | 設計目的 |

## 6. vehicles_1 / bicycle 成因分析

針對 `vehicles_1` 中 `bicycle (8)` rebound，後續用已完成的 checkpoints 做了診斷分析，不重新跑 unlearning。分析使用 CIFAR-100 test split，追蹤 vehicles_1 五類每張 test image 在 step0-step5 的 prediction、top-k、logit margin、feature centroid / PCA、mask overlap 與 parameter delta。

目前最重要的結論是：`bicycle` 比其他 vehicles_1 類別更像 `soft-forgotten`。它的 top-1 在 forget step 已經被壓到接近 0%，但 top-5 仍保留明顯訊號。

| Order | bicycle at forget top-1 | bicycle at forget top-5 | bicycle final top-1 | Recovered bicycle samples |
| --- | ---: | ---: | ---: | ---: |
| official | `0.0%` | `35.0%` | `43.0%` | `43/100` |
| random | `2.0%` | `34.0%` | `40.0%` | `39/100` |
| hardfirst | `1.0%` | `42.0%` | `48.0%` | `47/100` |

這組數字表示：模型確實在當步把 bicycle 從 top-1 壓下去，但很多 bicycle test images 仍在 top-5 候選中。後續 sequential unlearning 其他車輛類別時，只要 decision boundary 或 shared representation 有 drift，這批接近邊界的 samples 就容易重新回到 top-1。

### 6.1 Margin 與 sample-level recovery

Recovered bicycle samples 不是 1-2 張偶然樣本，而是一批穩定樣本群：

| Order | Recovered samples | Recovered mean margin at forget | Non-recovered mean margin at forget |
| --- | ---: | ---: | ---: |
| official | `43` | `-1.64` | `-2.88` |
| random | `39` | `-1.19` | `-2.34` |
| hardfirst | `47` | `-1.20` | `-2.88` |

Recovered samples 在 forget step 的 margin 比 non-recovered samples 更接近 0，代表它們本來就比較靠近 decision boundary。這支持「bicycle 是 soft-forgotten，後續 boundary drift 讓它回來」的解釋。

### 6.2 Mask overlap 不是主要原因

後續補做了固定 forgotten-class mask 的比較：把每個 class 被忘當下的 mask，拿去和後續 steps 的 masks 算 Jaccard overlap。

結果：

| Class | Later mask pairs | Average later Jaccard | Max later Jaccard |
| --- | ---: | ---: | ---: |
| bicycle `(8)` | `10` | `0.489` | `0.526` |
| bus `(13)` | `8` | `0.523` | `0.583` |
| motorcycle `(48)` | `6` | `0.508` | `0.538` |
| pickup_truck `(58)` | `3` | `0.519` | `0.534` |
| train `(90)` | `3` | `0.510` | `0.522` |

`bicycle` 的 average later-mask Jaccard 是 `0.489`，反而低於其他 vehicles_1 類別平均約 `0.515`。因此目前不能說 bicycle rebound 是因為 bicycle mask 和後續 masks 特別重疊；mask overlap 只能作為「後續 updates 會改動共享參數區域」的輔助證據，不是主因。

### 6.3 Feature Centroid / PCA 的解讀

Feature 分析改成看三個時間點，而不是只看 final：

1. `baseline / step0`
2. `bicycle forget step`
3. `final / step5`

Centroid distance 的重點如下：

| Order | bicycle forget step 最近 vehicle centroid distance | final 最近 vehicle centroid distance |
| --- | ---: | ---: |
| official | `11.69` | `4.86` |
| random | `3.52` | `4.76` |
| hardfirst | `10.09` | `5.00` |

不能只用 final PCA 說 bicycle 一直和其他車輛重疊；更合理的說法是：後續 vehicle unlearning steps 會明顯改變 feature space，使 bicycle 在 final 時靠近 vehicles_1 / vehicles_2 的 shared feature region。不過 centroid 本身不能單獨證明因果，仍要和 top-5、margin、sample recovery 一起看。

綜合目前證據，最保守也最合理的解釋是：

> `bicycle (8)` 被忘當下 top-1 幾乎歸零，但 top-5、margin 與 feature representation 仍保留部分 candidate signal。後續忘其他車輛類別時，shared vehicle representation 或 classifier boundary 被重新調整，使這批 soft-forgotten bicycle samples 又回到 top-1。

### 6.4 哪些已驗證，哪些仍是推論

目前已經用現有結果驗證的部分：

| 結論 | 狀態 | 關鍵數字 |
| --- | --- | --- |
| bicycle 是 post-forget rebound，不是當步忘不掉 | 已驗證 | forget step `0/2/1%`，final `43/40/48%` |
| bicycle 是 soft-forgotten | 已驗證 | forget step top-5 `35/34/42%`，但 top-1 `0/2/1%` |
| 其他 vehicles_1 類別大多是 hard-forgotten | 已驗證 | bus / motorcycle / pickup / train 的 forget top-5 大多 `0%` |
| rebound 不是少數樣本雜訊 | 已驗證 | recovered bicycle samples `43/39/47` 張 |
| 早忘不是充分條件 | 已驗證 | motorcycle step1、bus step1 都沒有 rebound |
| bicycle 的 mask overlap 沒有特別高 | 已驗證 / 不支持 mask 主因 | bicycle Jaccard `0.489`，其他類別平均約 `0.515` |
| 後續 vehicle steps 會改變 feature / boundary 狀態 | 有證據支持 | final 最近 vehicle centroid distance 約 `4.86/4.76/5.00` |

仍然屬於合理推論、尚未完全驗證的部分：

| 推論 | 需要什麼驗證 |
| --- | --- |
| bicycle rebound 是否一定是 vehicle-specific update 造成 | 需要跑 `bicycle_then_flowers` 與 `bicycle_then_vehicles2` |
| bicycle 是否因為視覺特徵更分散、class-specific cue 較弱，所以比較難深度忘記 | 需要做 image-level / feature separability 分析 |
| bicycle rebound 是否能透過更強 forgetting 消失 | 需要跑 `bicycle_stronger_then_vehicles1_seed1_k5`，觀察 forget-step top-5 是否下降與 final rebound 是否消失 |
| 這個現象是否跨 seed 穩定 | 需要跑不同 seed |

因此，目前可以確定的是：`bicycle` 的確被忘得比較「淺」，而且後續會穩定 rebound；但更深層的原因，例如為什麼 bicycle 比其他車輛更容易 soft-forgotten，仍需要控制實驗才能更強地證明。
